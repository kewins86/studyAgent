> 版本：V1.0（三年级·沪教版 MVP）
> 日期：2026-08-10
> 配套：`seed_data/k9_grade3_profile_questionnaire_20260810.md`（21 题问卷内容）
> 原型预览：`design/profile_questionnaire_preview.html`（浏览器直接打开）

---

## 一、设计目标

1. **答题人 = 家长**：三年级孩子无法自主填问卷，页面文案面向家长（"您孩子/孩子"），口语化、无教育术语。
2. **5-8 分钟完成**：21 题分 5 步（每步一屏），必答 14 题，选答题明确标注"选答"。
3. **移动端优先**：uni-app 小程序 + H5 双端，单手可操作，大点击区域（≥88rpx）。
4. **降低流失**：进度可视化 + 草稿自动保存，中途退出不丢。
5. **合规透明**：页面明示数据用途，不采集姓名/学校/住址。

## 二、信息架构（5 步流程）

```
欢迎页(简短说明) → A 基本信息(3题) → B 学习情况(5题) → C 态度性格(6题) → D 内容偏好(4题) → E 使用预期(3题) → 提交成功(标签预览)
```

| 步骤 | 内容 | 题数 | 必答 | 预计耗时 |
|---|---|---|---|---|
| 欢迎页 | 一句话说明 + 预计 5-8 分钟 + 隐私承诺 | - | - | 10s |
| A 基本信息 | 年级 / 数学水平 / 昵称 | 3 | 2 | 1min |
| B 学习情况 | 辅导方式 / 遇难反应 / 成绩趋势 / 每日时长 / 辅导班 | 5 | 4 | 1.5min |
| C 态度性格 | 兴趣 / 坚持 / 表扬 / 专注 / 粗心 / 挑战（李克特） | 6 | 6 | 2min |
| D 内容偏好 | 学习方式 / 讲解节奏 / 错题态度 / 情境主题 | 4 | 2 | 1min |
| E 使用预期 | 使用目标 / 反馈频率 / 设备时长限制 | 3 | 0 | 1min |

## 三、视觉规范

### 配色（知鹿金主题，源自 App Logo 主色）

| 色名 | 色值 | 用途 |
|---|---|---|
| 主色 | `#F0A000` 知鹿金 | 选中态、按钮、进度 |
| 主色浅 | `#EAF1FE` | 选中态背景 |
| 强调色 | `#E08E00` 深金 | 必答标记、标签高亮 |
| 成功 | `#34C759` | 完成态、勾选 |
| 背景 | `#F7F8FA` | 页面底色 |
| 卡片 | `#FFFFFF` | 题目卡片 |
| 文字主 | `#1F2937` | 题目 |
| 文字次 | `#6B7280` | 说明、选答标记 |
| 分割线 | `#EEF0F3` | 卡片内分隔 |

### 字体与圆角

- 字体：系统栈（PingFang SC / 苹方），题目 32rpx 中、选项 30rpx、说明 24rpx
- 圆角：卡片 24rpx、按钮 44rpx（全圆角胶囊）、选项 16rpx
- 间距：页面左右 32rpx，卡片内 32rpx，题间距 40rpx
- 点击区：选项高度 ≥96rpx

### 组件样式

1. **顶部导航**：返回箭头 + "第 X/5 步" + 分区名；下方 5 段式进度条（已完成段主色填充）
2. **题目卡片**：白底圆角卡，题号徽标（橙色圆角小方块"Q1"）+ 题目 + （选答/多选限N项 灰色小标签）
3. **选项**：
   - 单选：整行大卡片，左图标右文字；选中 = 主色边框 3rpx + 浅蓝底 + 右侧圆形勾
   - 李克特：5 档横向圆点滑选（非常符合 → 完全不符），选中圆点放大 + 主色填充，下方标注两端语义
   - 多选限 N 项：卡片可多选，右上角计数徽标"已选 1/2"，超限震动提示
   - 填空：圆角输入框，占位示例，≤10 字
4. **底部操作区**：固定底栏，主按钮"下一步/提交"（主色胶囊，未满足必答时置灰）；E 步之前有"上一步"文字按钮
5. **合规小字**：页面底部固定"信息仅用于为孩子定制学习内容，不会对外分享"

## 四、交互设计

| 场景 | 行为 |
|---|---|
| 必答校验 | 点"下一步"时校验本步必答题，未答 → 按钮置灰 + 未答题卡片轻微抖动 + 红点标记 |
| 选答跳过 | 选答题不答直接下一步，卡片灰色"选答"标签弱化 |
| 多选超限 | 点第 3 项时不可选 + toast"最多选 2 项" |
| 草稿保存 | 每题作答即写本地 storage（uni.setStorageSync），重新进入恢复；欢迎页显示"继续上次填写" |
| 返回上一步 | 已答内容保留，可修改 |
| 提交成功 | 全屏成功态：打勾动画 + "画像已生成"，展示 3 个代表标签（如：主动性强 · 专注力中 · 喜欢游戏闯关），按钮"开始学习"跳首页 |
| 中断离开 | 未提交离开 → 下次进入提示"上次填写到第 X 步，是否继续？" |

## 五、技术实现要点（uni-app Vue3）

### 页面与组件拆分

```
src/pages/profile/questionnaire.vue      # 问卷主页面（步骤状态机）
src/components/question/
  ├── QSingle.vue     # 单选卡片（props: options, value）
  ├── QMulti.vue      # 多选限N项（props: options, max, value）
  ├── QLikert.vue     # 李克特5级（props: labels, value）
  └── QText.vue       # 文本填空（props: placeholder, maxlength, value）
```

### 状态管理（Pinia）

```js
// src/stores/questionnaire.js
const answers = ref({})        // { q1: 'A', q9: 4, q15: ['A','B'], q3: '乐乐' }
const currentStep = ref(0)     // 0=欢迎 1-5=A-E
const finished = ref(false)
// 每次 setAnswer 后 uni.setStorageSync('qn_draft', {answers, currentStep})
```

### 后端标签聚合（已设计，见问卷文档第四节）

问卷 → 10 个标签 → 存入 `student_profiles` → 驱动差异化对话提示词（挑战/鼓励/趣味/陪伴四象限）。

## 六、无障碍与合规

- 按钮、选项点击区 ≥96rpx，文字对比度 ≥4.5:1
- 隐私明示：欢迎页 + 底部常驻小字
- 可清除：设置页提供"重置画像"（MVP 预留入口）
- 不采集：真实姓名（昵称选填）、学校、住址、分数排名
